# 폰트 사용 개념

- 사용자를 위한 폰트는 구체적이고 가독성이 좋아야 한다.
- 보이지 않는 폰트, 계층이 나뉘지 않는 폰트는 지양한다.
- 가독성 좋은 폰트, 유행을 타지 않는 폰트가 최고의 폰트
- 폰트를 돋보이게 하는건 폰트 자체가 아닌 문단 형태, 간격, 폰트 크기

### 폰트 가이드 4가지 포인트

1. 디자인시 지켜야 하는 최소 행간, 자간, 어간
2. 최소로 지켜야 하는 기본적인 폰트 가이드
3. 사용자에게 의미를 전달하는 폰트 강약 밸런스
4. 시스템 폰트를 선정하는 방법과 사용 팁

### 1. 시스템폰트

- 컴퓨터에 깔려 있는 기본 폰트 (굴림체, 돋움체, 맑은고딕, 애플고딕 등)
- 제작자가 만든 텍스트와 방문자가 보는 텍스트의 폰트가 동일하게 보인다.

### 2. 웹폰트

- 의도한 폰트를 사용자 화면에 출력하기 위해 다운로드 받는 폰트
- 디자이너가 사용한 웹폰트가 방문자의 컴퓨터에 깔려있지 않은 폰트라면 이를 대체하는 폰트로 출력
- 그런데 서버에 이 웹폰트를 올려놓으면 방문자가 사이트에 접속시 바로 웹폰트를 다운받아 표시
- 다만, 접속했다는 이유만으로 방문자의 컴퓨터에 웹폰트가 자동으로 설치되지는 않는다.

### 3. 이미지폰트

- 포토샵 등으로 제작한 글자를 이미지 그대로 보여주는 폰트
- 포토샵이나 그래픽 프로그램을 사용하여 이미지 그대로 캡쳐하여 표시
- 이미지로 만든 텍스트이기 때문에 방문자의 컴퓨터에 폰트가 없거나 서버에 웹폰트를 올려놓지 않아도 됌
- 이미지기 때문에 용량이 크면 트래픽 문제가 발생하고, 텍스트를 수정할 때마다 그래픽 작업이 필요

### 폰트 기본 가이드

- 폰트 자간(국문) : 자간 0%, -2.5%
- 폰트 자간(영문, 숫자) : 자간 0%, -2.5%
- 국문 영문 함께 사용시 자간 -2.5% 로 통일
- 폰트 행간(국문, 영문)
  : 폰트 16 이전 -> 행간 145%
  : 폰트 16 ~ 32 이전 -> 행간 140%
  : 폰트 32 ~ 32 이후 -> 행간 130%

### 폰트 가독성 올리는 법

- 몇 줄까지 가독성이 좋을까? : 3줄
- 영문 폰트 사용 방법 : 항상 소문자를 같이 사용
- 영문 폰트 고를 때는 i, l, I, L 등 구분이 잘 되는지 확인
- 시스템 폰트를 사용할 때 기본요소인 강약과 여백으로 사용자에 의미와 뜻을 전달하는 게 중요

## 디자이너가 바라보는 폰트

- 사용자는 표준 서체에 더 익숙하기 때문에, 표준 서체를 쓰면 더 빨리 읽을 수 있다.
- 브랜딩 목적, 몰입의 경험 등 특별한 서체가 필요한 상황이 아니면, 시스템 서체가 베스트.
- 좋은 폰트는 서체 자체로 독자의 눈길을 끄는 게 아닌 내용에 관심을 갖게 하는 것

# Typography Guide (MO)

- 폰트는 국문 영문 모두 Pretendard 통일을 원칙
- 폰트 속성은 Semibold, Regular, Light 3가지만 또는 Bold, Mediume, Regular 3가지만 사용

### 폰트 크기 (한글)

- Display1 ~ Display6 : 56, 48, 40, 36, 32, 28
- Headline1 ~ Headline6 : 32, 28, 24, 20, 18, 16
- Title1 ~ Title4 : 24, 20, 18, 16
- Body1 ~ Body4 : 15, 14, 13, 12
- Caption1 ~ Caption3 : 13, 12, 11

### 폰트 크기 (영문, 숫자)

- Display1 ~ Display6 : 80, 72, 64 56, 48, 40
- Headline1 ~ Headline6 : 32, 28, 24, 20, 18, 16
- Title1 ~ Title4 : 24, 20, 18, 16
- Body1 ~ Body4 : 15, 14, 13, 12
- Caption1 ~ Caption3 : 13, 12, 11

# 컬러 개념

컬러는 기업의 분위기, 콘셉트 등 아이덴티티를 상징하며,
고객들의 기억에 각인시키는 강력한 효과를 지니고 있으며,
접근성을 고려해 사용자의 불편함을 최소화 시키는 시스템 컬러를 사용하여 정보 전달

### 브랜드 컬러

- 브랜드 메인 컬러 1개와 서브 1~2개를 정의하여 사용
- 브랜드 컬러를 너무 많이 사용할 경우 정작 보여주고자 하는 정보를 못 보여줄 수 있다.
- 브랜드 컬러는 버튼, 라인, 폰트 등 강조하고자 하는 곳에 다양하게 사용
- 그라이언트 활용 시 메인 컬러와 서브 컬러를 우선적으로 조합하여 사용
  (Main 100% ~ Main 0%, Main 100% ~ Sub_1 100%, Main 100% ~ Sub_2 100%, Sub_1 100% ~ Sub_2 100%)

### 사용범위와 배색 비율

서비스의 성격이나, UI 콘셉트, 주 컬러에 따라 적절한 비율 설정
배색 비율을 찾기 어렵다면 메인 컬러를 제외하고 1가지만 사용하는 것도 방법

- 화이트 / 블랙 계열
  : 배색 비율에 화이트, 블랙 계열 컬러는 포함되지 않는다.
  : 모든 디자인에 공통으로 사용되는 컬러로 여백을 의미
  : 다만 브랜드 컬러가 화이트, 블랙인 경우 배색 비율을 어느정도 고려

### UI는 색감이 기본적으로 많다

컬러를 사용하지 않아도 배너, 아이콘, 이미지 등 다채로운 색감들이 자리 잡고 있기 때문에
최대한 절제해서 사용하는 것이 사용자에게 전달하고자 의미를 명확하게 보여줄 수 있다.
컬러 조합이 어렵다면 흰 바탕에 중요한 곳에만 컬러를 사용하는 것도 방법

### 폰트 컬러

- 폰트 컬러는 4가지로 최소화 (비활성화 포함)
- 폰트 컬러는 접근성을 고려한 4.5:1 이상 컬러를 사용
- 비활성화 컬러는 접근성에 위배되지만 계층구조를 나타내기 어려울 시 예외로 사용
- Main Text Color : #111111
- Sub Text Color : #505050, #767676
- Disabled Color : #999999

### 아이콘 컬러

- 아이콘 컬러는 5가지로 최소화 (비활성화 포함)
- 추후 유지보수를 위해 아이콘만 컬러를 변경할 수도 있어 폰트 컬러와 다르게 정의
- Main Icon Color : #2A2A37, #FFFFFF
- Sub Icon Color : #545461, #81818D
- Disabled Icon Color : #A5A5AF

### 라인 컬러

- 라인 컬러는 총 3가지의 기준
- 버튼, 인풋박스, 셀렉트박스 등에는 중간 라인 컬러 #E5E5EC 사용
- Light Color : #F1F1F5 (화이트 BG에서 적극 사용)
- Regular Color : #E5E5EC (연한 그레이 BG에서 적극 사용, 버튼, 셀렉, 인풋 컬러에 사용)
- Black Color : #111111 (화이트 BG에서 적극 사용)

### BG 컬러

- BG 컬러는 총 2가지의 기준
- BG 컬러를 사용할 경우 폰트 컬러는 #505050 이하로 사용하면 안된다.
- Light Color : #F7F7FB
- Regular Color : #F1F1F5

### 상태 컬러

- 상태 컬러는 3가지로 요약 정의
- 빨강, 초록만 사용하는 경우도 많다.
- 금지, 실패, 위험, 정지 등 : #D32F2F
- 성공, 진행, 안전 등 : #00C853
- 주의, 경고, 실수 등 : #FBC02D

## 색감에 의존하지 말자

- 컬러는 절제해야 비로소 가치가 있다.
- 감각에 의존해서 사용하는 컬러 배합은 의미를 전달할 수 없다.
- 다채로운 컬러를 배합하면 중요한 브랜드 컬러를 놓칠 수 있다.
- 컬러 사용이 어렵다면 많이 사용하는 것보다 오히려 다 빼는 게 더 좋다.

# 스플래시 인트로

- 모바일 앱이나 소프트웨어를 실행할 때 가장 먼저 나타나는 초기 로딩 화면
- 주로 기업의 로고, 브랜드 이름, 대표 이미지 또는 짧은 애니메이션이 표시
- 내부 데이터가 완전히 로드될 때까지 보통 1~3초 동안 유지
- 지루함 방지 및 인상 설계, 브랜드 아이덴티티 강화, 데이터 로딩 시간 확보
- 768x1024 사이즈로 제작 후 2배수로 내보낸다.
- 모바일 너비를 고려하여 영역을 설정
